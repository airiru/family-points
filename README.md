# 家庭积分榜（阿里云 ESA 边缘函数版）

多成员积分管理系统：自定义计分规则（如"按时睡觉 +1"、"晚睡半小时 -3"）、积分排行榜、自定义兑换商城、历史记录。所有数据保存在**阿里云 ESA 边缘 KV**，多成员访问共享同一份数据。

整个项目只有一个文件 `index.js`（边缘函数），页面由函数直接返回，无需构建。

## 部署步骤

1. **创建 KV 存储空间**
   登录 [ESA 控制台](https://esa.console.aliyun.com/) → 左侧导航「边缘计算和 AI」→「KV 存储」→「创建存储空间」，
   空间名称填 **`jifen`**（如果想用别的名字，需同步修改 `index.js` 顶部的 `KV_NAMESPACE`）。

### 方式一：边缘函数（推荐，无构建步骤）

2. **创建边缘函数**
   「边缘计算和 AI」→「边缘函数」→ 创建函数，把 `index.js` 的全部内容粘贴到在线编辑器中并部署。

### 方式二：ESA Pages（连接 GitHub 仓库自动部署）

创建 Pages 项目并导入本仓库即可。仓库已含 `esa.jsonc`：

- `entry: "./index.js"` — 指定边缘函数入口；
- `installCommand` / `buildCommand` 留空 — 本项目单文件、无依赖，跳过安装和构建（之前报 "Build command execution failed" 就是因为 Pages 试图对纯单文件项目执行 npm 构建）。

Pages 模式下所有请求都会由该函数处理（无静态资源），行为与边缘函数方式一致。若在控制台改过构建配置，注意仓库中 `esa.jsonc` 的优先级更高。

3. **绑定路由**
   给该函数绑定一个路由（例如你的站点 `example.com/*`），使所有请求都走这个函数。
   函数对非 `/api/*` 的 GET 请求直接返回网页，`/api/*` 为数据接口。

4. 打开绑定的域名即可使用，手机浏览器访问也很方便，建议"添加到主屏幕"。

## 功能说明

- **成员页**：按积分实时排名（🥇🥈🥉），可添加/删除成员、快捷"记一笔"；点击成员名字可查看其全部记录并支持积分清零
- **计分规则页**：自定义规则名称和分值，正数加分、负数减分，可随时增删
- **记一笔页**：选成员 → 点规则，一步完成计分；规则外的临时事项可用"自定义记一笔"直接填名称和 ± 分值
- **兑换商城页**：自定义物品和所需积分，选择成员兑换，积分不足会提示
- **记录页**：最近的加减分和兑换记录（最多保留 500 条），可按成员筛选

## 访问口令（可选）

默认无鉴权，任何拿到网址的人都能改数据。如需保护，编辑 `index.js` 顶部：

```js
const PASSCODE = '你家口令'; // 留空 = 不启用
```

设置后部署，首次打开网页会弹出输入框要求输入口令，输对一次后保存在浏览器里，之后不再询问。网页本身不含数据，数据接口全部经过口令校验。

## 注意事项

- 边缘 KV 写入后需要短暂时间同步到全球节点，家庭使用场景下延迟可忽略。
- KV 最终一致：极小概率下两人同时写会有一次写入被覆盖，日常家庭使用几乎不会遇到。
