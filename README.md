# 家庭积分榜（Vue 3 + 阿里云 ESA 版）

多成员积分管理系统：自定义计分规则（如"按时睡觉 +1"、"晚睡半小时 -3"）、积分排行榜、自定义兑换商城、历史记录。前端为 **Vue 3 + Vite**，数据接口由 **ESA 边缘函数** 提供，数据保存在**阿里云 ESA 边缘 KV**，多成员访问共享同一份数据。

## 项目结构

```
├── index.html          # Vite 入口 HTML
├── src/                # Vue 前端
│   ├── main.js         # 应用入口
│   ├── App.vue         # 全部页面（成员/规则/记一笔/商城/记录）
│   ├── api.js          # API 层：fetch 封装 + 口令鉴权 + 错误提示
│   └── style.css       # 全局样式
├── worker/index.js     # 边缘函数：/api/* 数据接口（EdgeKV 读写）
├── esa.jsonc           # ESA Pages 部署配置（构建命令、函数入口、资源目录）
├── dev-server.mjs      # 本地联调服务器（托管 dist/ + 模拟 /api，仅开发用）
└── vite.config.js
```

## 部署（ESA Pages，连接 GitHub 仓库）

1. **创建 KV 存储空间**
   登录 [ESA 控制台](https://esa.console.aliyun.com/) → 左侧导航「边缘计算和 AI」→「KV 存储」→「创建存储空间」，
   空间名称填 **`jifen`**（如果想用别的名字，需同步修改 `worker/index.js` 顶部的 `KV_NAMESPACE`）。

2. **创建 Pages 项目**
   「边缘计算和 AI」→「函数和 Pages」→ 创建 Pages，导入本 GitHub 仓库。仓库中的 `esa.jsonc` 已配置好：
   - `installCommand: npm install`、`buildCommand: npm run build`（Vite 构建前端到 `dist/`）；
   - `assets.directory: ./dist`（托管构建产物）；
   - `entry: ./worker/index.js`（边缘函数处理所有未命中静态资源的请求，即 `/api/*`）。

3. 推送代码到 GitHub 后 Pages 会自动构建部署，之后每次 push 自动更新。

4. 打开分配的域名即可使用，手机浏览器访问也很方便，建议"添加到主屏幕"。

## 本地开发

```bash
npm install
npm run dev        # Vite 开发服务器（页面可看，API 需另外起服务）
node dev-server.mjs  # 或：构建后本地联调（托管 dist/ 并模拟 /api，数据存内存）
```

## 功能说明

- **成员页**：按积分实时排名（🥇🥈🥉），可添加/删除成员、快捷"记一笔"；点击成员名字可查看其全部记录并支持积分清零
- **计分规则页**：自定义规则名称和分值，正数加分、负数减分，可随时增删
- **记一笔页**：选成员 → 点规则，一步完成计分；规则外的临时事项可用"自定义记一笔"直接填名称和 ± 分值
- **兑换商城页**：自定义物品和所需积分，选择成员兑换，积分不足会提示
- **记录页**：最近的加减分和兑换记录（最多保留 500 条），可按成员筛选

## 账号登录与权限

账号在网页里管理，**无需改任何配置文件**：

- **首次部署**后打开网页，会要求创建管理员账号（一次性初始化，签名密钥自动生成）；
- 管理员登录后进入「后台设置」→「账号」标签，即可添加账号、删除账号、切换角色（管理员/查看者）、重置密码；
- **管理员**可看主页 + 后台设置，进行所有修改；**查看者**只能看主页（排行榜、成员详情、最近记录），后端同样拒绝其修改请求；
- **绑定成员与自助兑换**：在「账号」标签里可以把一个账号绑定到一个成员（一个成员只能绑一个账号）。绑定后，该账号登录时主页会出现"兑换商城"，可以用**自己的积分**直接兑换物品（余额不足时按钮禁用），兑换会写入记录；
- 服务端保证至少保留一个管理员，且不能删除当前登录的账号；
- 密码加盐哈希后存入边缘 KV，登录凭证（HMAC 签名 token）保存在浏览器里，**30 天**免登录，右上角可随时退出；账号被删除后其登录凭证立即失效。

## 连续打卡奖励（自定义）

在「后台设置」→「计分规则」里，添加规则时可以额外填写"每 N 天 / 奖 M 分"（选填）：该规则每连续打卡 N 天，自动额外奖励 M 分并写入记录（达到 2N、3N 天再奖，中断后重新计数，一天内多次打卡不重复计天，按东八区计算）。例如：按时睡觉 +2 分、每连续 7 天奖 3 分。不填则只是普通计分规则。主页和后台的成员卡片会显示 🔥 连续天数；规则列表中也会标注奖励设置。

## 注意事项

- 边缘 KV 写入后需要短暂时间同步到全球节点，家庭使用场景下延迟可忽略。
- KV 最终一致：极小概率下两人同时写会有一次写入被覆盖，日常家庭使用几乎不会遇到。
