## 环境与工具坑（本机新增，长期有效）

- **本机 Git Bash 的 mingw64 curl（8.21）把非 ASCII 命令行参数按 GBK 交给服务器**：
  内联 `-d '{"nickname":"中文"}'` 存进库全是 U+FFFD，回归大面积假红；
  `--data-binary @file` 则正确。修法：`/tmp/ubin/curl` 包装器 exec
  `/c/Windows/system32/curl.exe`（System32 版 wmain，参数 UTF-8 正确），跑脚本时
  `PATH=/tmp/ubin:$PATH`。**跑任何含中文请求体的验收脚本都必须带这个 PATH**。
  python.exe 不受影响（走 GetCommandLineW）。
- **本机 MySQL**：phpstudy `D:/phpstudy_pro/Extensions/MySQL8.0.12`，root 密码
  经用户同意已重置为 `FpRoot2026`（写入 `server/.env` 的 DB_PASSWORD，**不入库**）。
  `--skip-grant-tables` 在 8.0.12 会强制 skip_networking（port=0），要走命名管道
  `--named-pipe=1` + `mysql --pipe` 改密，然后正常重启。
  familypoints 库是 11-07 新建的（`CREATE DATABASE utf8mb4` → `migrate` → `-seed-admin`）。
- **Git Bash 后台进程**：`cmd &` 在命令结束常被杀；起常驻进程用
  `powershell Start-Process -FilePath '<windows路径>' -WorkingDirectory '<windows路径>'`。
  /tmp 映射 `C:\Users\airiru\AppData\Local\Temp`。
