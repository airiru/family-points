## 续9：P1 认证完成（19 项接口测试全通过）

### 已定结论

1. **默认管理员 = `admins` / `admins`**（用户指定），由 `go run ./cmd/migrate -seed-admin` 初始化，
   取 `ADMIN_USERNAME`/`ADMIN_PASSWORD`；**已有管理员则跳过**（幂等，避免重复部署重置密码）。
   新账号一律 `must_change_password=1`。
2. **refresh token 一步到位：落库**（用户拍板）。新增 `refresh_tokens` 表，只存 SHA-256 哈希，
   支持**轮换**（旧的立即置 `revoked_at`、写 `replaced_by_hash`）与**全量吊销**（改密后）。
   纯无状态 JWT 做不到主动失效，这是选它的唯一理由。
3. **用户名/密码规则**（原文档没有，本次定并写入 5.1.4/5.1.5）：
   用户名 3–20 位仅字母数字下划线；密码 ≥8 位、≤72 字节（bcrypt 上限），不要求复杂度。
4. **Access Token 里不放角色**，每次请求从库读 `members.role`（否则换组长后旧 token 仍有权限）。
